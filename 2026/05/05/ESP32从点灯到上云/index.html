（三）外网篇：WebSocket 隧道穿透内网

问题

ESP32 在局域网内，外部网络无法直接访问。没有公网 IP，也不想配置路由器端口转发。

ESP32 主动连接服务器的 WebSocket 端口，建立持久通道。外部 HTTP 请求到达服务器后，通过 WebSocket 转发给 ESP32 处理，ESP32 再把响应发回。

  1. WebSocket 服务（端口 9000）：等待 ESP32 连接，token 认证
  2. HTTP 服务（端口 8081）：接收外部请求，转发给 ESP32

main.cpp 集成

访问方式

浏览器访问 http://你的服务器IP:8081，请求流程：

  1. 浏览器 → 服务器 HTTP 端口
  2. 服务器 → WebSocket → ESP32
  3. ESP32 执行控制，返回响应
  4. 响应原路返回浏览器

小结

  • WebSocket 长连接天然穿透 NAT，无需端口转发
  • Token 认证防止未授权访问
  • 断线自动重连保证可靠性
  • 请求-响应 JSON 协议简单直观

（四）上云篇：华为云 IoTDA 接入

为什么用 IoT 平台

自建隧道虽然能用，但缺少：

  • 设备管理（在线/离线状态、固件升级）
  • 数据存储（历史数据、规则引擎）
  • 规模化能力（多设备、多用户权限）

华为云 IoTDA（IoT Device Access）提供完整的设备接入能力。

小结

  • IoTDA 基于 MQTT 协议，轻量高效，适合嵌入式设备
  • 平台提供设备管理、命令下发、属性上报完整能力
  • 通过规则引擎可以联动其他华为云服务（如 DIS、OBS）
  • 安全性由 TLS + Token 保证

总结

阶段 技术栈 控制范围 复杂度
（一）基础 FastLED + FreeRTOS 本地 ★
（二）局域网 WebServer + LittleFS 局域网 ★★
（三）外网 WebSocket 隧道 公网 ★★★
（四）上云 MQTT + 华为云 IoTDA 公网 + 平台 ★★★★

每一步都在前一步的基础上增加能力，代码模块化设计使得切换非常方便——只需在 main.cpp 中切换 include 和初始化不同的模块即可。

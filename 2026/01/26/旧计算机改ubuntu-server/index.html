旧笔记本“抢救”计划 —— Ubuntu Server 安装与网络填坑实录

一、 硬件与环境准备

  • 设备：闲置笔记本电脑（全程连接电源）。
  • 介质：8GB+ U 盘（使用图吧工具箱/Rufus 制作启动盘）。
  • 镜像：Ubuntu Server 24.04 LTS（放弃桌面环境，追求极致性能）。

二、 BIOS 与启动逻辑

  • 热键：联想系列常用 F2 或 Fn + F2 进入 BIOS；F12 进入启动项选择。
  • 关键设置：
    • Secure Boot：若安装过程中识别不到驱动或无法启动，建议将其设为 Disabled。
    • SATA Mode：确保设为 AHCI（如果是旧机器）。

三、 安装阶段的“逻辑抉择”

在安装引导界面，有两个点需要特别注意：

  1. 版本选择：
    • Standard vs. Minimized：强烈建议选 Standard。Minimized 版本虽然精简，但缺少很多基础网络工具和补丁，后期手动安装极其痛苦。
    • Third-party Drivers：务必勾选。对于旧笔记本的无线网卡、闭源固件，这是“续命”的关键。
  2. 磁盘方案（LVM 的陷阱）：
    • Ubuntu 默认的 Guided LVM 逻辑非常保守，仅分配 50% 的空间给 /（根目录）。
    • 操作建议：在分区界面手动调整 ubuntu-lv 的大小，将所有 Free Space 分配给根目录，避免出现“明明有 500G 硬盘，用两天就提示空间不足”的尴尬。

四、 攻克无线网络“硬件锁”

这是本次安装最大的“坑”：安装时配置了 WiFi 密码，开机后却显示 state DOWN 且无法联网。

1. 现象定位

  • 执行 ip link：网卡状态（wlp2s0）为 DOWN。
  • 查看硬件状态：cat /sys/class/rfkill/rfkill*/state 输出为 0（代表硬件被屏蔽/锁定）。
